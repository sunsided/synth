pub struct TrackerState {
    pub song: Song,
    pub presets: Vec<Patch>,
    pub cursor_row: usize,
    pub cursor_track: usize,
    pub octave: i8,
    pub show_help: bool,
    audio_ok: Arc<AtomicBool>,
    player: Player,
    event_tx: Sender<AudioEvent>,
}
Expand description

All mutable state owned by the UI thread.

Fields§

§song: Song

Song being edited.

§presets: Vec<Patch>

Loaded preset bank.

§cursor_row: usize

Cursor row (step index, 0..song.pattern.len).

§cursor_track: usize

Cursor track column (0..TOTAL_TRACKS).

§octave: i8

Current keyboard octave for note entry.

§show_help: bool

true → show the help overlay.

§audio_ok: Arc<AtomicBool>

false once the CPAL stream reports a fatal error.

§player: Player

Background playback thread.

§event_tx: Sender<AudioEvent>

Channel for direct audio events (patch loads, panics).
