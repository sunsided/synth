Background playback thread: step-sequencer engine.

Player::spawn starts a dedicated thread that listens on a control channel. The UI thread drives it via Player::play, Player::stop, and Player::update_song.

The current step index and playing state are exposed through Arc<AtomicUsize> / Arc<AtomicBool> so the UI can read them lock-free each frame without blocking the audio callback.
