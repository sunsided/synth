Module tracker 

Source
Expand description

Core data model for the step-sequencer tracker.

A Pattern holds a fixed grid of Steps (rows × synth tracks) plus a parallel DrumStep column. The Song bundles one pattern with a BPM setting and per-track preset assignments.
