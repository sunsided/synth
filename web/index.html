SYNTHIE

A chiptune synthesizer engine in Rust, with two terminal front-ends — compiled to WebAssembly and running right here in your browser.

Synth

Play the SID-style synth from your keyboard and tweak oscillators, filter, envelopes, LFOs and FX live.

Tracker

A step sequencer with four synth tracks and drums, preloaded with the Lazy Jones / Kernkraft 400 hook.

Needs a keyboard. The first key press starts audio; F1 shows all keys. Source on GitHub · engine on crates.io · API docs on docs.rs
