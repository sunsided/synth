Initialise CPAL audio output with NUM_CHANNELS synthesis channels.

Convenience wrapper around setup_audio_n. For a custom channel count call setup_audio_n::<N>() directly.

§Errors

Returns an error if no default audio output device is available or if the stream configuration cannot be determined or opened.
