Expand description

Per-channel arpeggiator with phase-accumulator timing.

Lives inside AudioChannel. All timing state is here; note-list state lives in ArpParams so it survives param snapshots sent via LoadPatch.

Fields§

§phase: f32

Fractional position within the current step, 0.0..1.0.

§step: u8

Index into the active note list.

§sounding: Option<MidiNote>

Note currently held by the arp; None when between steps.

§gate_fired: bool

true once NoteOff has been emitted for the current step’s note.

§direction: u8

Direction flag for UpDown mode: 0 = ascending, 1 = descending.

§lfsr: u32

Galois LFSR state for Random mode.

pub fn tick(&mut self, sample_rate: f32, params: &ArpParams) -> ArpEvents

Advance one sample and return any note events that fire this sample.

Call once per sample from inside the audio render loop. When both off and on are Some, apply off first.

The increment params.rate / sample_rate is clamped to [0, 1], so phase always stays in [0, 1) after each call. Rates >= sample_rate are treated as one step per sample.

pub fn remove_note(&mut self, params: &mut ArpParams, note: MidiNote)

Remove note from the arp list, shifting the remaining entries down.

When the last note is removed (count drops to 0) the playback state is reset so a subsequent add_note starts from a clean position. The caller (AudioChannel::note_off) is responsible for releasing any voice that was sounding at that moment.

Source

pub fn set_notes(&mut self, params: &mut ArpParams, notes: &[MidiNote])

Replace the arp list with notes (up to 4 entries) and reset playback state.

Source

pub fn panic(&mut self, params: &mut ArpParams)

Clear the arp list and all playback state.

AudioChannel::panic() silences voices directly afterwards, so no NoteOff event is needed here.
