Binary entry point for the synth TUI application.

Owns TUI runtime bootstrap, event loop, terminal lifecycle, and user-preset file I/O. Core DSP and parameter types are imported from the synth library.

The application layer (app), visualisation (viz), and preset persistence (preset_store) are binary-local modules declared here.
